MeshCore Desktop v0.4

NEW

Trace message: A new view on the Map / Network tab, beside Map and Graph. A note above the map says "Double-click a message to see the path it took". Double-click a received message and its path is drawn in red, from the sender through each repeater to you. The map zooms to fit it, each stop has a numbered tooltip, and the note shows the route and any stop with no location. Live packet lines are hidden in this view. With the Map / Network panel open, double-clicking a message switches to this view automatically. With it closed, double-click still replies, and Ctrl+R or the right-click menu always replies.

Resizable tiled panels: Drag the grip between two panels to resize them. Panels no longer scroll sideways. Their content reflows to fit instead: message bubbles wrap, the Dashboard stacks its tiles and charts, and the Repeater screen drops to one column of values with its buttons wrapped underneath. A panel won't shrink below 320 px, so nothing gets cut off.

Flood a direct message: In a DM, a Flood button at the top right forgets the stored path to that contact, so the next message floods the whole mesh and their reply sets a fresh path. While there's no stored path it reads "Flooding" and is greyed out. Clicking the contact's name at the top opens their menu: Reset path, Show on map, Copy public key, and Manage repeater for repeaters.

The ⋯ menu: Send advert, Forget pairing, Message details (Ctrl+I), Compact layout (Ctrl+M) and Accent colour are now in a menu at the right end of the toolbar.

CHANGED

One toolbar row: The view chips moved into the main toolbar, so content starts higher on the screen. The right side shows the node name, battery %, the connection status, and Connect or Disconnect. Radio settings and firmware are in the tooltip on the node name. The view chips are hidden until a node is connected.

Live packets on the map: The Map view now shows only live packets. Each received packet draws its path as it arrives, holds for a few seconds, then fades, with at most 6 shown at once. The Network mode, which drew permanent links between nodes, has been removed.

Message details: The details panel stays hidden until you click a message, and closes with × or Ctrl+I. It used to take up width all the time.

Panel title bars: A panel's title bar only shows when two or more panels are open. A single panel fills the space.

Small screens: The window opens no larger than your screen, and the sidebar is narrower (280 px, down from 340). Compact mode now keeps normal-size text and only tightens the spacing.

Map legend: The legend is a single row, so it no longer covers half of a small map.

FIXED

Messages word-wrap to the panel again when it's resized. Bubbles used to keep their old height after a resize and overlap, and a long route under a DM's name could hold the panel wider than its tile.

The Repeater panel fits its tile: Status is now the first tab beside Console, Settings, History and Live, long pages scroll inside their tab, and the two advert buttons are one Advert ▾ menu.

A DM's route now updates as soon as the node learns a new path. It used to change only when the whole contact list reloaded.

"1 hops" now reads "1 hop".

The Refresh button on the Repeater screen no longer covers the "Updated" time in compact mode.

The stray "·" in front of each view chip's label is gone.

The gaps between tiled panels are clean instead of thick grey bars.
