MeshCore Desktop v0.4: changes since v0.3
==========================================

This release is mostly about the layout: a cleaner look, and a window that
works on a small laptop screen.


Toolbar
-------
- One toolbar row instead of two. The view chips (Messages, Map / Network,
  Repeater, Dashboard) moved into the main toolbar.
- The right side shows the node name and battery %, the connection status,
  Connect or Disconnect, and a new ⋯ menu.
- The ⋯ menu holds the occasional actions: Send advert (zero-hop or flood),
  Forget pairing, Message details (Ctrl+I), Compact layout (Ctrl+M) and
  Accent colour.
- The radio settings and firmware version moved into the tooltip on the
  node name.
- The view chips are hidden on the welcome screen until a node is connected.
- Fixed a stray "·" in front of each view chip's label.


Panels and window
-----------------
- A panel's title bar only shows when two or more panels are open. A single
  panel fills the space.
- Tiled panels resize properly. Drag the grip between two panels.
- Panels never scroll sideways. Their content reflows to fit the width:
    - Messages: bubbles wrap to the panel width.
    - Dashboard: below about 620 px, the stat tiles go two to a row and the
      charts stack.
    - Repeater: below about 600 px, the status and settings values drop to
      one column, the buttons wrap under the password field, and the battery
      gauge moves under the values.
    - Map: the search box shrinks and the filters fold into the Filters menu.
- A panel stops shrinking at 320 px, so nothing gets cut off.
- The gaps between tiled panels are clean, not thick grey bars.
- The sidebar is narrower: 280 px, down from 340.
- The window opens no larger than the screen. It used to open at
  1250x780 even on a 768 px-tall laptop.


Messages
--------
- The message details panel is hidden until you click a message. Close it
  with × or Ctrl+I. It used to take 290 px of width all the time.
- The conversation header is tighter.


Map / Network
-------------
- The Network mode is gone. The tab now has three options: Map, Graph and
  Trace message.
- Received packets draw their path on the map: a dot runs along each hop and
  the line draws in behind it, stays about 2.5 s, then fades. At most 6
  paths show at once. This needs a flood packet (relayed at least once),
  your node's location, and at least one located repeater on the path.
- The map legend is one row, so it no longer covers half of a small map.
- New "Trace message" view next to Map and Graph. A note above the map says
  "Double-click a message to see the path it took". Double-click a received
  message and its path is drawn in red: sender, each repeater, then you. The
  map zooms to fit it, each stop has a numbered tooltip, and the note shows
  the route and any stop without a location. Live packet lines don't show
  in this view, only the traced message. Double-clicking a message while the
  map panel is open switches to this view by itself. With the map closed,
  double-click still replies, and Ctrl+R or the right-click menu always
  replies.
- The Map view shows only live packets; traced paths stay in Trace message.


Repeater
--------
- In compact mode, the Refresh button no longer covers the "Updated" time.
  It now sits under the battery gauge.


Compact mode
------------
- Compact mode keeps normal-size text and only tightens the spacing. It used
  to shrink the font to 12 px.


Other
-----
- README: the screenshot table no longer has the Network map, and the
  Map / Network description is updated.
- Note: the other README screenshots still show the v0.3 layout.
